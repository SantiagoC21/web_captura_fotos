Política de Privacidad

Última actualización: 14 de septiembre de 2026

Esta aplicación ("Captura Facial UNI") es un proyecto académico desarrollado en la Universidad Nacional de Ingeniería (UNI) con fines de investigación y aprendizaje en reconocimiento facial. Esta política describe qué datos se recopilan y cómo se utilizan.

Datos que recopilamos

  • Código de estudiante (Código UNI)
  • Nombres y apellidos
  • Aula o curso asociado
  • Fotografías del rostro capturadas mediante la cámara del dispositivo

Finalidad del tratamiento

Los datos recopilados se utilizan exclusivamente para la construcción de un dataset facial con fines académicos, dentro del marco de un proyecto universitario de reconocimiento facial. No se utilizan con fines comerciales.

Almacenamiento

Las fotografías y datos asociados se almacenan en una base de datos privada y en una cuenta de Google Drive controlada por el responsable del proyecto. No se comparten con terceros ajenos al proyecto académico.

Acceso a Google Drive

Esta aplicación utiliza la API de Google Drive únicamente para que el responsable del proyecto (no los usuarios finales) pueda almacenar de forma organizada las fotografías capturadas durante el proceso de registro.

Derechos del usuario

Cualquier persona cuyos datos hayan sido capturados puede solicitar la eliminación de su información y fotografías contactando al responsable del proyecto mediante el correo indicado a continuación.
